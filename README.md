MediaApp (Thread-Clone)

This Threads clone is a minimalist social platform designed for real-time public conversations and direct private messaging. Built with the MERN stack, it features secure user authentication and a dynamic home feed for posting text-based "threads" with multimedia attachments. The core interaction includes likes, replies, and reposts, supported by a robust follow system to curate user content. Key to its real-time experience is an integrated Chat functionality powered by Socket.io, enabling instant, private peer-to-peer messaging. The project combines the public engagement of a microblogging site with the private connectivity of a messaging app in one seamless React interface.
